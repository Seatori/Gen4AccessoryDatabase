# Pokemon Generation 4 Accessory Database
A database of accessories in Generation 4 of Pokemon, allowing you to search for where they are obtained and get a list of optimal accessories for each theme in Diamond, Pearl & Platinum's Super Contests.
To use, simply download `gen_4_accessories.py` from the repository, and run it on your computer. Requires Python 3.10 or later.
At this time, customizing which accessories have been obtained for the Super Contest display requires modifying the script directly.
